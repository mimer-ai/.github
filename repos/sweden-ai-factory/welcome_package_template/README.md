# Example of AI workload on a EuroHPC machine

Brief description of the usecase

## Quick start

Describe how to run and if/how it differs between clusters. The .slurm files contain skeletons for you to fill.

In `tools` you can put things like data prefetchers or other secondary scripts.
`src` has the main file(s), `logs` all the slurm output files and `output` is
where you save models (if you need). 
There is a simple `train.py` file with an argparse, maybe it's a good starting point, maybe not.
